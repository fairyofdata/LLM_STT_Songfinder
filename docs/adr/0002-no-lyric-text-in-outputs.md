# ADR-0002: 가사 원문을 어떤 산출물에도 새로 내보내지 않는다

- 상태: 채택
- 결정일: 2026-10-21
- 기록: 2026-10-22 소급 작성 (근거: [연구개발 기록](../RESEARCH_LOG.md))

## 맥락
가사는 저작권 대상이다. 공개 레포에 이미 올라가 있는 메타데이터 문제는 사용자가 따로 처리하기로 했다. 이번 작업으로 노출을 늘리지는 않아야 한다.

## 결정
- 결과 JSON, 차트, README, 문서, 로그, 커밋 메시지에 가사 문장을 넣지 않는다. 질의는 id, 곡 인덱스, 원본 줄 인덱스로만 기록한다.
- 가사가 필요한 중간물은 레포 밖 `~/.cache/songfinder_eval/`에 둔다. TTS 음성, 전사문, 사람 검수 시트가 여기에 해당한다.
- 오류 메시지에 가사가 담길 수 있으면 id와 상태 코드만 출력한다.
- 커밋 전마다 결과·문서·스크립트 전체를 대상으로, 6자 이상 가사 줄과 요약문이 포함됐는지 자동 검사한다(마지막 검사 34개 파일 0건).

## 결과
- 결과만으로는 질의 문장을 볼 수 없다. 필요하면 시드와 id로 로컬에서 다시 만든다.
- 문서의 예문은 직접 쓴 문장만 쓴다.
