# ADR-0003: 정답 단위는 곡이고, 줄 검색 결과를 곡으로 묶는다

- 상태: 채택
- 결정일: 2026-10-21
- 기록: 2026-10-22 소급 작성 (근거: [연구개발 기록](../RESEARCH_LOG.md))

## 맥락
앱은 가사 줄을 검색하지만 사용자에게 필요한 것은 곡이다. 후렴처럼 같은 줄이 여러 곡에 있으면 정답이 모호하다.

## 결정
- 정답은 `original_song_index`로 정한다. 가사 줄 top-2048을 곡으로 묶어 처음 나온 순서로 중복을 없앤 순위로 Recall@1/5/10과 MRR을 계산한다.
- 원본 줄이나 질의 문자열이 정규화 후 다른 곡의 줄과 같으면 「모호」로 표시하고 따로 집계한다.
- 원본 줄은 공백 제외 8자 이상만 쓴다(앞 절반 질의가 너무 짧아지지 않도록).

## 결과
- 모호 질의는 시드당 87~109개(대부분 인접 두 줄 유형)다. 정확히 같은 줄만 모호로 보므로, 한 글자 차이 같은 거의 같은 줄은 「모호하지 않음」에 남는다.
