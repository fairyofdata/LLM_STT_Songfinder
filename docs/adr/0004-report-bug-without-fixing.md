# ADR-0004: 요약 분기 버그는 고치지 않고 두 변형을 평가해 보고한다

- 상태: 채택
- 결정일: 2026-10-21
- 기록: 2026-10-22 소급 작성 (근거: [연구개발 기록](../RESEARCH_LOG.md))

## 맥락
`search_pipeline_from_text`는 요약 검색이 이기면 `line_metadata[I_summary[0][0]]`로 곡을 찾는다. 그런데 `I_summary`는 곡 인덱스라 결과가 곡 0~6번으로만 나온다. 앱 수정 여부는 사용자가 결정한다.

## 결정
- 「현행」과 「고친 변형(`I_summary[0][0]`을 곡 인덱스로 사용)」을 모두 평가한다.
- 가사 질의에서는 요약 분기가 발동하지 않는다(0%). 그래서 버그 범위를 보이려고, 요약문을 질의로 쓰는 탐침을 추가한다.

## 결과
- 탐침 결과: 현행 0.2% vs 고친 변형 100%(요약 전체), 1.1% vs 37.1%(요약 앞 절반).
- 수정은 한 줄이지만 아직 적용하지 않았다(사용자 결정 대기).
