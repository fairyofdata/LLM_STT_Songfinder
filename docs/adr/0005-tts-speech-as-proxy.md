# ADR-0005: TTS 음성은 사용자 음성의 대용으로, 상대 비교에만 쓴다

- 상태: 채택
- 결정일: 2026-10-21
- 기록: 2026-10-22 소급 작성 (근거: [연구개발 기록](../RESEARCH_LOG.md))

## 맥락
실제 사용자 녹음이 없다. 사용자가 「TTS로 평가하는 게 맞나」를 물었다.

## 결정
- TTS 음성으로 잰 값은 「깨끗하고 또박또박한 낭독일 때의 낙관적 상한」으로만 해석한다. 다음 용도에만 쓴다.
  - 조건 간 상대 비교(발음, 길이, 언어 설정, 음질)
  - 오류 원인 분해(전사 탓인지 검색 탓인지)
  - 회귀 시험
- 같은 회사 조합(OpenAI TTS → `whisper-1`)의 편향을 줄이려고, 다른 회사 TTS 3종, 목소리 29개, 채널 증강을 쓴다.
- 「실사용 음성 정확도」라는 표현은 쓰지 않는다. 실사용 수치는 소수 인원의 실제 녹음으로만 낸다(미실시).

## 결과
- OpenAI 조합(75.6%)과 로컬 조합(76.2%)의 한 줄 결과가 거의 같았다. 엔진 편향은 작아 보인다.
- 노래, 콧노래, 사람의 말투는 여전히 측정하지 않았다.
