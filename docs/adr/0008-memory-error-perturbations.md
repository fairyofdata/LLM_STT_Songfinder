# ADR-0008: 기억 오류는 문절 단위 7유형으로 흉내 내고, 사람이 맹검으로 검수한다

- 상태: 채택
- 결정일: 2026-10-21
- 기록: 2026-10-22 소급 작성 (근거: [연구개발 기록](../RESEARCH_LOG.md))

## 맥락
처음 교란(단어 누락, 오타)은 「뜻은 기억하는데 단어가 다른」 경우를 재지 못했다. 사용자는 ELECTRA·디퓨전식 치환과 누락을 제안했다. 형태소 단위 1차 시도에서는 다음 문제가 생겼다.
- 활용 어미가 깨짐
- 다른 문자 체계로 바뀜(직접 쓴 예문에서 空 → TV)
- 영어 자리에 덴마크어 단어가 들어감

## 결정
- 단위는 문절(내용어 + 뒤따르는 조사·조동사)이다. 유형은 일곱 가지다.

  | 유형 | 방법 |
  |---|---|
  | 동의어 | WordNet 동의어 중 가사 DB에 있고 읽기가 다른 말을, XLM-R 문맥 가능도로 고름 |
  | 소리 비슷한 말 | 가나 읽기가 한 모라만 다른 같은 품사 단어 |
  | 조사 | 같은 종류 안에서 바꾸거나 뺌 |
  | 어절 빼기 | 문절을 통째로 뺌 |
  | 문맥상 그럴듯한 말 (ELECTRA식) | 같은 문자 체계·품사·활용의 다른 말. 영어 자리는 DB에 있는 영어 단어만 |
  | 같은 읽기 다른 표기 | 한자 단어를 같은 읽기의 다른 표기나 가나로 |
  | 섞기 | 앞의 넷을 무작위로 섞음 |

- 강도는 문절의 20/40/60%다. 유형 간 비교는 모든 유형이 적용되는 공통 원본 줄로만 한다.
- 「사람이 이렇게 잘못 기억할 법한가」는 표본 100개를 유형을 가린 맹검으로 사람이 0/1/2로 판정한다. 판정 전에는 「교란 강건성」으로만 부른다.

## 결과
- 뜻에는 강하고 소리·표기에는 약하다는 결론이 나왔고, 가나 읽기 색인을 개선 후보로 삼았다.
- 검수 판정은 아직이다.
