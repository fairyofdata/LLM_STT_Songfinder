# ADR-0009: 불확실성은 곡 단위 부트스트랩, 짝지은 비교는 McNemar로 낸다

- 상태: 채택
- 결정일: 2026-10-21
- 기록: 2026-10-22 소급 작성 (근거: [연구개발 기록](../RESEARCH_LOG.md))

## 맥락
처음에는 시드 간 표준편차(±0.6%p)만 냈다. 하지만 그것은 「같은 450곡 안에서 어느 줄을 뽑느냐」의 변동일 뿐이다. 질의는 곡 안에 묶여 있다(한 곡에서 여러 줄과 여러 유형을 만듦).

## 결정
- 비율 지표의 95% 신뢰구간은 곡을 복원 추출하는 클러스터 부트스트랩(2,000회)으로 낸다(`eval/stats.py`).
- 같은 질의를 조건만 바꿔 비교할 때는 McNemar 정확 검정을 쓰고, 「새로 맞음 대 새로 틀림」 개수를 함께 보고한다.

## 결과
- 전체 Recall@1의 신뢰구간은 59.8~61.5%다.
- 여전히 「이 450곡」에 대한 추론이다. 다른 곡 목록이나 실제 사용자로의 일반화는 보장하지 않는다.
