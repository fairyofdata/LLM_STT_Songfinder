# ADR-0010: 교란 곡선은 시드 5개 대신 3개로 확정한다

- 상태: 채택
- 결정일: 2026-10-22
- 기록: 2026-10-22 소급 작성 (근거: [연구개발 기록](../RESEARCH_LOG.md))

## 맥락
교란 곡선 계산(CPU에서 XLM-R 사용)이 음성 실험(Supertonic CPU)과 CPU를 다투면서, 시드당 18분이던 것이 60분 이상으로 늘었다. 사용자는 진행 속도를 걱정했다.

## 결정
- 이미 끝난 시드 0~2로 확정하고 3번째 이후는 중단한다.
- 근거: 세 시드의 결과가 서로 1~2%p 안에서 같았고, 공통 원본 줄 1,607개의 곡 단위 신뢰구간 폭이 ±2~3%p라 결론이 바뀌지 않는다.

## 결과
- 원래 설계(시드 5개)에서 바뀐 사항으로 평가 상세(`docs/EVALUATION.md`)와 기록에 명시했다.
- 다시 돌리려면 `run_noise.py --seeds 0 1 2 3 4`를 실행한다.
