# ADR-0012: 개선안 효과는 앱을 바꾸지 않고 기존 전사문으로 추정하고, 따로 떼어 둔 질의로 확인한다

- 상태: 채택
- 결정일: 2026-10-22
- 기록: 2026-10-22 소급 작성 (근거: [연구개발 기록](../RESEARCH_LOG.md))

## 맥락
앱 수정은 사용자 결정 사항이다. 하지만 「무엇을 고치면 얼마나 나아지는가」가 있어야 결정할 수 있다.

## 결정
- 이미 저장된 전사문만으로 다음 세 가지를 다시 검색해 추정한다(`eval/audio_fixes.py`).
  1. 한국어로 감지되면 `language="ja"` 전사로 대체
  2. 줄 길이(14자) 조각 투표 + 전사문 전체 1표(조각 수의 제곱근 가중)
  3. 둘을 함께 적용
- 투표 가중치는 0.5/1/2 중 같은 데이터에서 골랐다. 그래서 다른 시드로 만든 여러 줄 입력 질의(각 449개)로 효과를 따로 확인한다.

## 결과
- 한국인 발음 35.6 → 69.3%(156 대 5), 원어민 5줄 47.2 → 74.4%. 한 줄은 변화가 없다.
- 따로 떼어 둔 질의에서도 61 → 91%, 65 → 95%로 재현됐다.
- 실제 앱에 넣으면 추가 전사의 지연과 비용(한국어로 감지된 경우만)이 생긴다. 이 효과는 아직 실측하지 않았다.
